# Запуск стартового проекта

Панель заявок службы поддержки — без сервера и без сборки.

## Как запустить

Откройте `index.html` двойным щелчком (или File → Open в браузере).
Если браузер ругается на `localStorage` при открытии файла напрямую
(`file://`), запустите локальный сервер:

```bash
python3 -m http.server 8000
```

## Что нужно сделать

Базовая функциональность уже работает: форма добавляет заявку в
очередь, список сохраняется в `localStorage`. Ваша задача — добавить
**одну** ИИ-функцию: классификацию заявки по категории — «Техническая»,
«Оплата» или «Возврат» — сразу при поступлении.

Место для реализации отмечено комментарием `// TODO:` в `script.js`,
функция `classifyTicket(text)` — замените заглушку на реальную
классификацию. В текущей версии проекта это уже сделано: категория
определяется по таблице правил `CATEGORY_RULES` (см. `README.md`).

Два допустимых уровня реализации:

1. **Простая эвристика** — без реального ИИ: по ключевым словам в
   тексте обращения (например «не работает»/«сломан» → Техническая;
   «оплатить»/«счёт»/«платёж» → Оплата; «вернуть»/«возврат»/«обмен» →
   Возврат).
2. **Вызов внешнего ИИ-API** — ориентир по переменным окружения — в
   `.env.example`, пример запроса — в `PROMPT_EXAMPLE.md`.

Категория показывается меткой рядом с заявкой (стиль `.ticket-category`
уже готов в `style.css`).

Файлы:

- `index.html` — разметка экрана
- `style.css` — стили
- `script.js` — логика; функция `classifyTicket` — то, что нужно было реализовать
- `.env.example` — переменные окружения для варианта с внешним API
- `PROMPT_EXAMPLE.md` — пример промпта для варианта с внешним API
