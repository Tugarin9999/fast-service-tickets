# Пример промпта — классификация заявки

Если решите подключить настоящий ИИ вместо эвристики, вот ориентир для
запроса (например, к OpenAI Chat Completions API).

## Системный промпт

```
Ты — классификатор заявок службы поддержки по ремонту бытовой
техники. Определи категорию присланного обращения и верни строго одно
слово: Техническая, Оплата или Возврат. Ничего больше не добавляй.
```

## Пользовательский промпт (подставляется текст обращения)

```
Текст обращения: "{{текст заявки}}"
```

## Ожидаемый ответ модели

Одно слово: `Техническая`, `Оплата` или `Возврат` — используйте его
как категорию, показанную рядом с заявкой.
