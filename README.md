# Панель заявок «Быстрый Сервис»

Статическая страница панели входящих заявок службы поддержки: клиент
отправляет обращение через форму, диспетчер видит общий список заявок, и
каждая заявка сразу помечена категорией — «Техническая», «Оплата» или
«Возврат».

Ни сервера, ни сборки, ни зависимостей: чистые `HTML` + `CSS` + `JS`,
заявки хранятся в `localStorage` браузера.

## Быстрый старт

Откройте `index.html` в браузере — этого достаточно. Если браузер
блокирует `localStorage` при открытии файла напрямую (`file://`),
поднимите локальный сервер:

```bash
python -m http.server 8000
```

и откройте `http://localhost:8000`.

## Как работает классификация

Функция `classifyTicket(text)` в `script.js` разбирает текст обращения по
таблице правил и возвращает одну из трёх категорий.

Правило — это регэксп и вес:

- **3** — явное намерение клиента, например «вернуть деньги»;
- **2** — однозначное слово: «оплата», «не работает», «возврат»;
- **1** — слабый признак: название техники, «слом».

Меткой становится категория с наибольшей суммой весов; при равенстве
решает порядок правил в таблице. Если не совпало ни одно правило,
подставляется «Техническая» — профиль компании (ремонт техники).

| Текст обращения | Категория |
| --- | --- |
| Стиральная машина не сливает воду и шумит | Техническая |
| Холодильник не морозит | Техническая |
| Счётчик воды не работает | Техническая |
| Не могу оплатить картой, терминал не работает | Оплата |
| Оплата не работает | Оплата |
| Хочу вернуть деньги за сломанный чайник | Возврат |
| Здравствуйте, хочу спросить | Техническая (по умолчанию) |

Перед сравнением текст приводится к нижнему регистру, `ё` заменяется на
`е` (так ловятся и «счёт», и «счет»), пробелы схлопываются.

Расширить словарь — дописать правило в `CATEGORY_RULES` (`script.js`) в
формате `[регэксп, вес]`.

## Структура проекта

- `index.html` — разметка: форма отправки и список заявок
- `style.css` — стили, включая вид метки категории `.ticket-category`
- `script.js` — логика: хранение заявок, классификация, отрисовка списка
- `ЗАПУСК.md` — инструкция по запуску и описание учебного задания
- `PROMPT_EXAMPLE.md` — пример промпта, если вместо эвристики подключить ИИ-API
- `.env.example` — пример переменных окружения для варианта с внешним API
  (сама страница их не читает)
- `AGENTS.md` — заметки для ИИ-агентов по работе с репозиторием

## Особенности и ограничения

- Классификация — эвристика по ключевым словам, без внешних запросов:
  текст обращения никуда не отправляется.
- Автотестов, линтера и сборки в проекте нет, проверка — в браузере.
- Заявки лежат в `localStorage` под ключом `fastservice-tickets`. Если вы
  изменили правила классификации, старые заявки сохранят прежние метки —
  чтобы увидеть новую классификацию, очистите ключ в DevTools →
  Application → Local Storage.
